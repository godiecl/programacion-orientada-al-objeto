# Programación Orientada al Objeto

Repositorio de código de apoyo para la asignatura **Programación Orientada al Objeto (POO)** del Departamento de Ingeniería de Sistemas y Computación (DISC), Universidad Católica del Norte (UCN), Chile.

Reúne ejemplos y proyectos en Java que ilustran los conceptos clave de la POO (abstracción, encapsulamiento, herencia y polimorfismo) para que puedas comprenderlos y aplicarlos en tus propios proyectos.

![Java](https://img.shields.io/badge/Java-21%20LTS-orange)

---

## Proyectos

| Proyecto                      | Descripción                                                                                                        |
|-------------------------------|--------------------------------------------------------------------------------------------------------------------|
| [`diccionario`](diccionario/) | Gestión de un diccionario de palabras y significados cargado desde un archivo de texto y ordenado alfabéticamente. |

## Requisitos

| Herramienta | Versión                                                                           | Descarga                                                                           |
|-------------|-----------------------------------------------------------------------------------|------------------------------------------------------------------------------------|
| JDK         | Java 21 LTS o superior                                                            | [Eclipse Temurin®](https://adoptium.net/temurin/releases/?version=21)              |
| IDE         | IntelliJ IDEA Community Edition (recomendado) o cualquier IDE compatible con Java | [IntelliJ IDEA Community v2025.2.6.3](https://box.disc.cl/intellij-2025.2.6.3.zip) |

## Primeros pasos

1. Instala el JDK y el IDE indicados en la sección [Requisitos](#requisitos).
2. Clona el repositorio:

   ```bash
   git clone https://github.com/godiecl/programacion-orientada-al-objeto
   ```

3. Abre la carpeta del proyecto que quieras trabajar (por ejemplo, `diccionario/`) desde tu IDE.
4. Consulta el `README.md` de cada proyecto para conocer su diseño, estructura y forma de ejecución.
